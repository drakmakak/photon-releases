# Photon

**Переписка, которая остаётся только между вами**

## Что внутри

| | |
|---|---|
| **Шифрование без компромиссов** | Каждое сообщение, звонок и файл шифруются от устройства до устройства. Ключи не покидают ваш телефон — даже мы их не видим. |
| **Голосовые и видео-кружки** | Записывайте кружки и голосовые в один тап — с той же защитой, что и текст. |
| **Чистые звонки** | Аудио- и видеозвонки с плавающим окном — продолжайте разговор, листая другие приложения. |
| **Предупредим о рисках** | Если телефон взломан (jailbreak) или подключился отладчик — вы узнаете об этом первыми. |
| **QR-верификация ключей** | Сверьте ключи собеседника одним сканом QR. |
| **Свой акцентный цвет** | Выберите акцент, светлую или тёмную тему — интерфейс сразу станет вашим. |

> **Вход только по приглашению.** Нет открытой регистрации и поиска по всей базе пользователей — только одноразовая ссылка или QR-код от того, кто уже там есть (код живёт 5 минут, работает один раз).

> **Несколько устройств — без облака с перепиской.** Подключайте телефон и Mac через подтверждение устройства (отпечаток ключа + QR); история сообщений не оседает на сервере «про запас».

## Как выглядит переписка

- **Список чатов без лишнего** — онлайн-статус, непрочитанные и группы, без ленты историй и рекламных карточек.
- **Текст, голос и реакции в одном чате** — голосовые сообщения, отметки прочтения, реакции; каждое сообщение зашифровано.
- **Меняющийся значок приложения** — смените значок на калькулятор, заметки или погоду в один тап.
- **Сверьте ключи вручную** — устройство подтверждается по отпечатку ключа и QR-коду.
- **Прозрачные предупреждения** — компрометация устройства или подключённый отладчик не остаются незамеченными.
- **Контроль в ваших руках** — устройства, звонки и приватность из одного места.

## Что под капотом

Несколько независимых слоёв защиты — а не одна галочка «шифрование включено». Если завтра сломают один слой, остальные всё равно держат оборону.

<details>
<summary><b>Транспорт</b></summary>

- **mTLS-сертификаты устройств** — свой внутренний CA выдаёт короткоживущие (7 дней) клиентские сертификаты, привязанные к Ed25519-ключу устройства.
- **OPAQUE PAKE для облачного пароля** — сервер никогда не видит сырой пароль, только результат протокола (Ristretto255 + Argon2).
- **Постквантовое рукопожатие** — ML-KEM поверх сессии.
</details>

<details>
<summary><b>Хранение на устройстве</b></summary>

- **2-из-3 капсула (Shamir)** — мастер-ключ базы разбит на device / hardware (Secure Enclave) / server шарды, любые 2 из 3 восстанавливают ключ.
- **Двухслойное шифрование БД** — XChaCha20-Poly1305 + AES-256-GCM, разные ключи.
- **MLS-хранилище** тоже шифруется тем же двухслойным способом.
- **Неразличимость Quick-код / Alarm-код** — оба хранятся как одинаковые по форме обёрнутые блобы.
</details>

<details>
<summary><b>Целостность устройства и приложения</b></summary>

- **Детектор jailbreak** — проверка путей, sandbox-escape записи, URL-схемы джейлбрейк-тулов, сканирование dyld.
- **Детектор отладчика** — в release-сборках.
- **Защита от скриншотов и записи экрана** — блюр при захвате экрана и уходе в фон, уведомление после скриншота.
</details>

<details>
<summary><b>Восстановление аккаунта</b></summary>

- **Seed-фраза** — настоящий BIP-39 словарь (2048 слов), 12 слов независимым выбором (~132 бита энтропии).
- **Quick-код / пароль** — Argon2 + XChaCha20-Poly1305.
- **Восстановление через облачный пароль** — по протоколу OPAQUE.
</details>

<details>
<summary><b>Анти-форензика и защита от принуждения</b></summary>

- **Alarm-код** — тихое стирание вместо разблокировки, без подтверждающих диалогов.
- **Полное локальное стирание** — БД, WAL/SHM/journal, вложения.
- **Лимит попыток разблокировки** — после 5 неудач требуется облачный пароль, после 3 неудач с ним — 5-минутная блокировка.
</details>

<details>
<summary><b>Сервер</b></summary>

- **Rate limiting** на логин/регистрацию/инвайты (Redis).
- **Удаление сообщения** после прочтения всеми получателями + отдельный TTL.
- **Проверка личности** на каждом запросе, не только при логине.
</details>

<details>
<summary><b>E2E-шифрование</b></summary>

- **Двойной ratchet для 1:1** с периодическим (~12–14ч) досогласованием ключей.
- **Реальный MLS** (RFC 9420, openmls) для групп.
- **Верификация ключей контакта** — отслеживает совпадение текущего ключа с ранее подтверждённым.
</details>

<details>
<summary><b>Маскировка</b></summary>

- **Смена иконки приложения** — альтернативные иконки (калькулятор, погода, заметки, облако) для маскировки под обычное приложение.
</details>

## Чем мы отличаемся

Не только обещание приватности — а способ её проверить.

| Критерий | Обычный мессенджер | Photon |
|---|:---:|:---:|
| Постквантовая криптография | Нет | **ML-KEM-1024** |
| Шифрование по умолчанию | Иногда | **Всегда** |
| Двойной ratchet + MLS для групп | Обычно только 1:1 | **Да, RFC 9420** |
| Обновление мастер-ключа | Хранится месяцами | **Каждые 7 дней** |
| Проверка ключей собеседника | Нет | **QR за секунду** |
| Оповещение о взломе устройства | Нет | **Да** |
| Защита от отладчиков в процессе | Нет | **Да** |
| Тихое стирание под принуждением | Нет | **Да** |
| Восстановление доступа | Только пароль/почта | **Seed-фраза + облачный пароль** |
| Кружки, голосовые и звонки | Есть | **Есть, зашифрованы** |
| Мультиустройство | Облачная копия переписки | **Синхронизация без хранения на сервере** |
| Смена значка приложения | Нет | **Да, включая маскировку** |
| Регистрация | Открытая | **Только по приглашению** |
