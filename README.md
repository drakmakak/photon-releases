# Photon

E2E-зашифрованный мессенджер с философией **Zero Trust ко всему**: серверу не
доверяют ни пользователь, ни устройство, ни ОС. Постквантовая криптография
(ML-KEM), настоящий end-to-end (double ratchet), локальное шифрование при
хранении на устройстве.

Сервер хранит только: хеш имени пользователя, зашифрованные credential-конверты
(OPAQUE), публичные ключи устройств, состав чатов (без имён — только хеши).
**Ничего из этого сервер прочитать не может.** История переписки, реальные
имена контактов, вложения — только на устройствах, в локально зашифрованной БД.

Это репозиторий официальных **бинарных сборок**. Исходный код — приватный.

## Скачать

**macOS** — [последний релиз](https://github.com/drakmakak/photon-releases/releases/latest)

Приложение пока не нотарифицировано Apple (в процессе) — при первом запуске
macOS покажет предупреждение "неизвестный разработчик". Чтобы открыть: ПКМ по
Photon.app → «Открыть» → подтвердить в диалоге (нужно один раз).

## Возможности

- Постквантовая криптография (ML-KEM-1024) на этапе установки соединения
- End-to-end шифрование сообщений, файлов, голосовых и видео-сообщений
- Блокировка скриншотов и записи экрана
- Локальное хранилище зашифровано at rest
- Единый дизайн на macOS и iOS

## Статус

В активной разработке. iOS-клиент — в закрытом тестировании.
